# Viloyatga Boramiz — demo

Open `index.html` in a modern browser. An internet connection is required for the free OpenStreetMap tiles, geocoding, and routing services.

This is a front-end prototype. Sign-in state and driver listings are stored in the current browser only; it is not a production account system or shared live taxi marketplace. Sample driver announcements are fictional.

Recent updates: driver routes use the same simple Qayerdan/Qayerga fields as passenger search; driver pricing asks how much they want to earn per passenger; signed-in role is remembered across reloads in the same browser; subtle UI animations added.
